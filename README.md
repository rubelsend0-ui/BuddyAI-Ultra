# BUDDY AI ULTRA — Production Android Personal Intelligence

Connected to Buddy AI Core (Spring Boot) via Cloudflare Tunnel.

## Build in Android Studio
1. Open this directory in Android Studio Ladybug/Meerkat.
2. Ensure JDK 21 is configured under Gradle Settings.
3. Select Build > Build APK(s).

## Cloud CI Build
Push to your GitHub repository on `main` branch. GitHub Actions builds `app-debug.apk` under the Actions tab.
